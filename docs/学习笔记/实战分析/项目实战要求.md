# 项目实战要求

基本要求：

​	一个人做两个项目：

- 基础项目选一个
- 其他项目选一个

**明确规定：代码量不得小于掌柜智库**

开发项目 -> 项目评估 -> 项目部署（参照课程的流程，进行GPU，CPU的分离部署）

需要将每日进度提交到在线文档中，并且需要将项目实时地同步到你的git仓库中，git仓库地址也需要写进来，一个项目一个仓库



## 如何从零开始开发项目（VibeCoding）

1. 理清需求
   1. 要做一个什么项目
   2. 是什么领域内的项目
   3. 这个项目完成了什么功能
2. 需要借助大模型能力帮你分析你的明确需求
   1. 输出一个需求文档
3. 将需求文档给大模型，让其生成项目相关文档
   1. 输出一个开发手册
4. 把开发手册给大模型进行开发
5. 解决需要部署的docker服务
6. 进行调试
   1. 能不能跑通
   2. 跑通后是否所有的服务，或者说所有的RAG流程都能运行呢
   3. 评估（RAGAS） -> csv记录指标 -> 让大模型针对性地进行调整
7. 部署 -> CPU GPU分离，将项目和所依赖的服务都通过docker容器化实现，部署在远程服务器上



补充需求：

为每个项目创建一个仓库，将仓库地址放在共享文档中

每天下午2:00,晚上9:00提交当日进度到共享文档中

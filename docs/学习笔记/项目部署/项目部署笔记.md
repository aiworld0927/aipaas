# 项目部署笔记

服务器 -> 跑项目

## 1.企业中如何去使用GPU资源去调用模型

三种方式

- 直接调API
- 租一个服务器，在服务器上跑模型服务
- 公司内部设置机房，自己部署服务

### 1.1直接调API

- 优点
  - 便宜，方便，不需要进行任何的前期投入
  - 可以调用很多的闭源模型
- 缺点
  - 网络稳定性（小缺点）
  - 数据隐私性（数据安全）
- 哪些公司倾向于使用这种方式
  - 大部分私企

### 1.2 租一个服务器

- 优点
  - 能够确保一定的安全性
  - 维护相对轻松一些
- 缺点
  - 稍微麻烦 -> 自己配置服务器
  - 数据隐私还是不太够
  - 需要花钱租服务器，需要前期投入
  - 只能部署开源模型

### 1.3 本机机房

- 优点
  - 数据隐私问题得到解决（社会工程学，也可以窃取隐私）
  - 后期成本会降低（后期是拿电费换token）
- 缺点
  - 前期投入巨大
  - 需要巨大的维护成本（硬件、软件都要维护）
  - 场地资源花费比较大
  - 只能部署开源模型
- 哪些公司倾向于使用这种方式
  - 军工
  - 国企
  - 有些大厂
    - 不希望技术泄露
    - 希望员工使用自己的模型
  - 一些私企
    - 涉及的业务比较隐私
